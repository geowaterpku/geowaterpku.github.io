GeoWater Lab Peking University

    Open research infrastructure

    Open data for
    river-centric hydrology.

    We develop and contribute reusable datasets that make river systems more observable, spatially explicit, and accessible to the hydrology community — from global river networks and naturalized discharge to dynamic catchment attributes and geomorphic floodplains.

    01
    GRADES
    Discharge
    River discharge · Global river network Data access forthcoming

    GRADES

    The first naturalized river discharge dataset at 2.94 million river reaches, developed for network-scale and global analyses of river-flow variability.

    2.94M river reaches Naturalized discharge Global scale

    Community extensions built on GRADES

    GRFR Derived community dataset developed from GRADES. Link forthcoming
    GRADES-hydroDL Data-driven extension developed from the GRADES river-flow framework. Link forthcoming
    02
    MERIT
    Basins
    Network
    River network · Local catchments Data access forthcoming

    MERIT-Basins

    Global vectorized flowlines and local catchments with a 25 km² channelization threshold, providing a consistent spatial framework for river-network analyses.

    25 km² threshold Flowlines + catchments Global scale

    Community modeling frameworks built on MERIT-Basins

    GRDR MERIT-Basins-based river-routing data and modeling framework. Link forthcoming
    MizuRoute MERIT-Basins-based river-routing model application. Link forthcoming

    MERIT-Hydro-Vectors

    Global vectorized flowlines with variable drainage density, enabling more flexible representation of river-network structure across diverse landscapes.

    Variable drainage density Vectorized flowlines Global scale
    04
    GSHA
    Hydrology
    Large-sample hydrology · Dynamic catchment attributes Data access forthcoming

    GSHA

    Large-sample hydrology datasets with annually varying land-cover statistics for river-centric studies of streamflow characteristics, hydrometeorology, and catchment attributes.

    Annual land-cover statistics Catchment attributes Large-sample hydrology
    05
    SHIFT
    Floodplain
    Geomorphic floodplains · Global Data access forthcoming

    SHIFT

    A global geomorphic floodplain dataset designed to represent spatial heterogeneity in floodplain form and support large-scale analysis of river–floodplain systems.

    Geomorphic floodplains Spatial heterogeneity Global scale
